# 99 - Archive

Folder ini digunakan untuk menyimpan dokumen historis, arsip kepengurusan masa lalu, dokumen yang telah didepresiasi, atau catatan rujukan yang tidak lagi aktif digunakan.

## Isi Direktori

- Berkas & dokumen periode lampau.
- Dokumen superseded/depresiasi.
- Catatan pembelajaran masa lalu.
