# Arsip Bukti Empiris (Evidence Archive)

Folder ini mendokumentasikan basis bukti empiris (*evidence-based diagnosis*) dari rekaman percakapan WhatsApp group civitas mahasiswa Program Studi Sistem Informasi PJJ Universitas Siber Asia (UNSIA) untuk penyusunan dokumen evaluasi dan reformasi tata kelola organisasi.

---

## Kebijakan Privasi & Pengecualian Penuh Git (*Data Protection Policy*)

> [!CAUTION]
> **Perlindungan Data Pribadi (UU PDP No. 27 Tahun 2022) — Full Ignore:**  
> Seluruh berkas teks log percakapan (`*.txt`), baik mentah (*raw*) maupun versi tersanitasi, berstatus **FULL IGNORE via `.gitignore` dan TIDAK di-commit ke repositori Git publik/terbuka**.
> 
> Berkas teks log percakapan tersanitasi yang sebelumnya sempat dirancang untuk di-track telah **dicabut (*revoked*)** demi kepatuhan hukum mutlak dan prinsip kehati-hatian (*zero-exposure risk*). Satu-satunya dokumen bukti yang di-track di Git adalah dokumen metrik sintesis agregat yang sepenuhnya bebas dari data pribadi: [`statistik-chat-evidence.md`](./statistik-chat-evidence.md).
> 
> Berkas mentah asli disimpan secara offline/lokal hanya untuk kebutuhan audit dan verifikasi internal tim reformasi.

## Catatan Penggunaan & Kepatuhan Etika

1. **Tujuan Penggunaan:**
   Seluruh data dalam arsip ini digunakan semata-mata untuk kepentingan evaluasi internal, reformasi tata kelola, perbaikan sistem layanan HIMA SI PJJ UNSIA, dan riset kelembagaan organisasi mahasiswa.
2. **Konteks & Keterbatasan:**
   - Rekaman percakapan mencerminkan persepsi dan pengalaman spontan mahasiswa di lapangan pada saat kejadian.
   - Nomor baris yang dirujuk dalam dokumen diagnosis mengacu secara spesifik pada baris teks berkas arsip lokal di direktori ini.
3. **Integritas Data:**
   Berkas teks mentah (*raw export*) dijaga integritasnya tanpa modifikasi isi percakapan agar dapat diaudit secara independen oleh pihak berwenang.
