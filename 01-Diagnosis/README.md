# 01 - Diagnosis

Folder ini memuat hasil evaluasi, survei, audit operasional, analisis data percakapan civitas, dan identifikasi akar masalah (*root cause analysis*) dari periode kepengurusan sebelumnya serta kondisi aktual saat ini.

---

## Dokumen Tersedia

1. [`01-diagnosis-kondisi-awal-hima.md`](./01-diagnosis-kondisi-awal-hima.md)
   Catatan diagnosis awal kondisi HIMA mencakup temuan observasi makro (D-01 s.d. D-11), hipotesis akar masalah kelembagaan (H-01 s.d. H-07), bukti validasi, dan pertanyaan klarifikasi.

2. [`02-diagnosis-masalah-berulang-awal-semester.md`](./02-diagnosis-masalah-berulang-awal-semester.md)
   Diagnosis mendalam berbasis bukti empiris percakapan WhatsApp civitas mengenai 3 masalah berulang di setiap awal semester: kekosongan panduan *onboarding* mahasiswa baru, drama pengisian/sinkronisasi KRS, dan kekacauan koordinasi pembagian grup kelas mata kuliah. Memuat temuan empiris (D-SEM-01 s.d. D-SEM-09) dan hipotesis akar masalah (H-SEM-01 s.d. H-SEM-05).
