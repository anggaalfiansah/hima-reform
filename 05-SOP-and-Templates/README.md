# 05 - SOP & Templates

Folder ini memuat Standar Operasional Prosedur (SOP) resmi organisasi, alur kerja (workflow diagram), dan dokumen template siap pakai.

## Dokumen SOP Tersedia

- [`SOP_seminar_KP.md`](./SOP_seminar_KP.md): Standar Operasional Prosedur pelaksanaan, pendaftaran, dan penjadwalan Seminar Kerja Praktik (KP).
- [`SOP_diseminasi_informasi_template.md`](./SOP_diseminasi_informasi_template.md): Standar Operasional Prosedur penyebaran informasi, kanal rilis, serta template posting publikasi.
