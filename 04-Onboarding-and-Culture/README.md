# 04 - Onboarding & Culture

Folder ini berisi materi orientasi untuk pengurus baru, pedoman nilai-nilai budaya kerja (nilai kolaboratif, transparansi, akuntabilitas), serta panduan komunikasi internal.

## Isi Direktori

- Panduan onboarding pengurus baru (100 hari pertama).
- Pedoman etika dan *code of conduct*.
- Ritme kerja, standar rapat, dan dokumentasi kerja tim.
