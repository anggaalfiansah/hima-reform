# 07 - Programs & Collaboration

Folder ini berisi rancangan program kerja (proker), inisiatif tematik, kalender kegiatan terpadu, dan pedoman kerja sama/kemitraan dengan pihak eksternal.

## Isi Direktori

### Inisiatif & Program Kerja Unggulan
- [`01-himsisfo-web-innovation-challenge.md`](./01-himsisfo-web-innovation-challenge.md):
  - **Program**: HIMSISFO Web Innovation Challenge (*"Build a Useful Web Solution"*).
  - **Fokus**: Kompetisi perancangan produk web fungsional bagi mahasiswa aktif UNSIA yang berorientasi pada pemecahan masalah riil (akademik, UMKM, produktivitas, sosial, dsb.).
  - **Fitur Khusus**: Sistem apresiasi setara (*Top 5 Best Web Projects*), berbasis pengumpulan link demo aktif (tanpa wajib video), kebebasan tumpukan teknologi, transparansi penggunaan AI & template, dan rubrik penilaian 5 aspek objektif (total 100 poin).

### Kerangka Program Lanjutan
- Master kalender kegiatan dan program kerja tahunan.
- Panduan kemitraan (MoU/MoA) dengan organisasi mahasiswa serumpun (*Tripartite Pact*), komunitas, dan industri teknologi.
